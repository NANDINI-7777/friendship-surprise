# 💌 Friendship Surprise Web Experience

An interactive, hyper-personalised digital gift web application built with **HTML5, Vanilla CSS, JavaScript, and IndexedDB**. Designed to craft memorable, interactive friendship day cards featuring dynamic photo galleries, video messages, tear-open envelope animations, and custom agreement pacts.

## ✨ Key Features

- 💌 **Tear-Open Envelope Animation**: Interactive paper-tearing CSS & JS animation that reveals a handwritten letter.
- 🏛️ **Museum of Us**: Personalized exhibit grid displaying key friendship milestones and memories.
- 📸 **Photo Gallery Slideshow**: Touch/mouse-swipeable polaroid photo gallery with custom captions.
- 🎬 **Video Message Support**: Upload and play custom video clips stored locally via IndexedDB.
- 🚨 **"Do-Not-Press" Interactive Button**: Playful escalating reaction button game.
- 📸 **Friendship Reel Memory Swiper**: Tinder-style memory swiping card deck (Keep vs. Forget).
- ✍️ **Friendship Renewal Pact**: Customizable agreement clauses with an interactive signing pad.
- 🎨 **6 Dynamic Color Themes**: Pink, Purple, Sunset, Ocean, Forest, and Gold themes.
- 🔗 **Zero-Backend Link Encoding**: All custom state is base64-encoded into the URL fragment (`#hash`).

---

## 💻 Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (CSS Variables, Flexbox, Grid, Keyframe Animations), JavaScript (ES6+)
- **Storage**: IndexedDB (for video media clips), LocalStorage (for compressed photo storage)
- **Deployment**: Vercel / GitHub Pages
